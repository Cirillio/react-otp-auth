# OTP Auth

Двухшаговая авторизация по номеру телефона с OTP-кодом.

## Флоу

1. Пользователь вводит номер телефона -> запрос на генерацию OTP
2. На телефон приходит код -> пользователь вводит 6 цифр -> получает токен
3. Токен сохраняется в `localStorage`, пользователь попадает на защищённый маршрут -> tanstack query делает запрос сессии (c хэдером Authorization: Bearer ${токен из локалстореджа}) и, если валидна, пускает пользователя, обновляя кеш сессии, иначе кидает на /auth/unauthorized.

## Стек

- **React** + **TypeScript**
- **Vite** - сборка
- **React Router** - маршрутизация
- **TanStack Query** - серверный стейт и мутации
- **React Hook Form** + **zod** - формы и валидация
- **Tailwindcss** - стилизация

## Запуск

```bash
bun install
bun dev
```

## Генерация типов с бэкенда

Типы для api контрактов генерируются автоматически из OpenAPI-схемы бэкенда с помощью [`openapi-typescript`](https://github.com/openapi-ts/openapi-typescript).

```bash
bun run type-gen
```

Скрипт забирает `openapi.json` (open-api.schema.json) с бэкенда и генерирует `src/types/api.ts`.

## Маршруты

| Маршрут         | Описание                                            |
| ---------------------- | ----------------------------------------------------------- |
| `/`                  | Главная страница приветствия      |
| `/auth/login`        | Форма авторизации (телефон -> OTP)   |
| `/profile`           | Защищённая страница после входа |
| `/auth/unauthorized` | Страница для неавторизованных    |
| `/auth/logout`       | Страница подтверждения выхода    |
