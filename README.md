# OTP Auth

Двухшаговая авторизация по номеру телефона с OTP-кодом.

## Флоу

1. Пользователь вводит номер телефона -> запрос на генерацию OTP
2. На телефон приходит код -> пользователь вводит 6 цифр -> получает токен
3. Токен сохраняется в `localStorage`, пользователь попадает на защищённый маршрут

## Стек

- **React** + **TypeScript**
- **Vite** - сборка
- **React Router** - маршрутизация
- **TanStack Query** - серверный стейт и мутации
- **React Hook Form** + **zod** - формы и валидация
- **Tailwindcss** - стилизация

## Запуск

```bash
bun install
bun dev
```

## Маршруты

| Маршрут    | Описание                                            |
| ----------------- | ----------------------------------------------------------- |
| `/auth/login`   | Форма авторизации (телефон -> OTP)   |
| `/welcome`      | Защищённая страница после входа |
| `/unauthorized` | Страница для неавторизованных    |
